# Питание в балансе

Самостоятельное веб-приложение с конструктором меню, расчётом КБЖУ и дневником питания, воды и веса. GitHub Pages публикует содержимое `web/`. Узнать адрес можно в настройках Pages.

## Дневник

Данные хранятся в браузере. Для переноса данных откройте «Личный кабинет» → «Скачать дневник» в прежней версии, затем «Личный кабинет» → «Загрузить дневник» в новой. Импорт заменяет записи и профиль на этом устройстве.

## Справочник и фото

КБЖУ в расширенном справочнике — на 100 г продукта. В архиве сайта хранится независимая от сервера поиска копия части справочника. Данные взяты из [Open Food Facts](https://world.openfoodfacts.org/) и распространяются под [Open Database License 1.0](https://opendatacommons.org/licenses/odbl/1-0/). Еженедельная сборка загружает обновления с Open Food Facts. Перечень содержит только товары с полным набором КБЖУ. Сайт не передаёт запросы посетителей в Open Food Facts. Модель распознавания блюд исполняется в браузере. Её лицензия и лицензия ONNX Runtime находятся в `web/assets/`.

## Локальная проверка

Из корня проекта выполните команды из шага `Restore and verify photo runtime` в `.github/workflows/pages.yml`, затем `node server.mjs`. Откройте http://localhost:8080. Для обновления каталога используется `python3 scripts/update-catalog.py`.
